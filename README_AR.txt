CineView - تحديث العناوين متعددة اللغات
======================================

ما الذي تغير؟
- cineview.py يجلب بيانات الفيلم بالعربية وقائمة عناوين TMDb المتاحة بلغات أخرى.
- build_article.py يبني مقالة Blogger واحدة بعنوان أساسي عربي، ويعرض العناوين المترجمة داخل نفس المقال.
- publish_article.py ينشئ مسودة للاختبار فقط.
- auto_publish.py ينشر المقال مباشرة كما كان في مسار النشر التلقائي، مع فحص published.json لمنع التكرار.
- لم يتم تضمين credentials.json أو token.json أو أي مفتاح API.

طريقة الاختبار في Termux:
1) احتفظ بنسخة احتياطية من مجلد CineView.
2) فك الأرشيف واستبدل ملفات Python الأربعة فقط:
   cineview.py
   build_article.py
   publish_article.py
   auto_publish.py
3) لا تستبدل credentials.json أو token.json.
4) اختر معرف فيلم غير موجود مسبقاً في data/published.json:
   export TMDB_MOVIE_ID=معرف_الفيلم
5) شغّل:
   python cineview.py
   python build_article.py
6) افحص data/article.html.
7) للاختبار الآمن أنشئ مسودة:
   python publish_article.py
8) النشر المباشر:
   python auto_publish.py

مهم:
- Blogger لديه عنوان منشور أساسي واحد. الترجمات الأخرى تظهر كعناوين داخل المقال نفسه، ولا تنشئ مقالات مستقلة.
- العناوين المترجمة تعتمد على الترجمات التي يوفرها TMDb؛ اللغات غير المتوفرة لا يتم اختلاق ترجمتها.
- هذا التحديث لا ينشر آلاف الأعمال دفعة واحدة؛ auto_publish.py الحالي يعالج الفيلم الموجود في data/movie.json فقط.
- لا تستخدم صيغة "مشاهدة" إلا إذا كانت الصفحة توفر فعلاً تجربة مشاهدة أو رابط مشاهدة قانونياً؛ وإلا عدّل قالب العنوان لتجنب وعد غير موجود.
- لا يضمن تعدد العناوين وحده فهرسة Google ولا يتجاوز أنظمة الحماية.
